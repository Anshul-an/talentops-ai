# Contributing to TalentOps AI

## Commit Conventions
Follow Conventional Commits specification:
- `feat:` New user-facing feature or API endpoint
- `fix:` Bug fix
- `docs:` Documentation updates
- `refactor:` Code refactoring without changing external behavior
- `test:` Adding or updating unit tests
- `chore:` Build scripts, configs, dependencies

## Pull Request Guidelines
1. Ensure all pytest tests pass: `pytest`
2. Follow PEP8 styling guidelines.
3. Keep commits atomic and focused.
